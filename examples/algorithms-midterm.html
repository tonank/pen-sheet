3. Find the Mistake — Binary Search Bound

A student wrote this binary search on a sorted array A[0..n-1]:

lo = 0; hi = n - 1
while lo < hi:
    mid = (lo + hi) // 2
    if A[mid] == target: return mid
    elif A[mid] < target: lo = mid
    else: hi = mid - 1
return -1

Identify two bugs, give a small counterexample input where it fails, and write the corrected loop.
